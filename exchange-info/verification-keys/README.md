# Verification Keys

For API withdrawals and transfers, signatures generated from Cube verification keys are required to be included in the request payload. For withdrawals and transfers executed through the Cube website or mobile app, this process is done for you. Note: verification keys are separate from API keys and API signatures.

The process for setting up and using verification keys involves a few steps:

* [Generate Verification Key](/exchange-info/verification-keys/generate-verification-key.md): Create a new key pair with one of the supported schemes
* [Register Verification Key](/exchange-info/verification-keys/register-verification-key.md): Send a request to Cube's API to register the newly generated verification key. The request should include a signature of the payload, generated by passing your Cube wallet's private key into a locally run signing algorithm that Cube provides in the public npm package [`@cubexch/electrum`](https://www.npmjs.com/package/@cubexch/electrum)
* [Withdraw with Verification Key](/exchange-info/verification-keys/withdraw-with-verification-key.md): You can then send withdrawal (or transfer) requests to the Cube API, including the verification key and a signature generated from that verification key in the payload.

See the example code on the next pages for details on how to generate, sign, register, and use verification keys. The full example is available [here](/examples/verification-keys/example.ts).
